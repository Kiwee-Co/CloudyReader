This page lists where Cloudy Reader stores files, the five preference keys it saves, and the limits built into the app.

## Data folder

The data folder holds the voices and the caches. It is `~/Library/Application Support/cloudyreader` unless you set `CLOUDYREADER_DATA_DIR`, described in [Command line](/manual/reference/command-line/). In Finder, choose **Go > Go to Folder** and paste the path.

### Contents

Each location below is relative to the data folder.

| Item                   | Location                   | Content                                                                                                                                               |
| ---------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Piper voices           | `voices/`                  | A `.onnx` file and a `.onnx.json` file for each voice.                                                                                                |
| Kokoro model           | `models/kokoro/`           | `config.json` and `kokoro-v1_0.safetensors`.                                                                                                          |
| Kokoro voices          | `models/kokoro/voices/`    | One `.safetensors` file for each voice.                                                                                                               |
| Chatterbox Turbo files | `models/chatterbox_turbo/` | The model files of the engine, in this folder or in one sub-folder.                                                                                   |
| Qwen3-TTS files        | `models/qwen3_tts/`        | The model files of the engine, in this folder or in one sub-folder.                                                                                   |
| Audio cache            | `cache/wav/`               | One WAV file for each distinct reading. The file name is a SHA-256 value. The cache has no size limit, and the app never cleans it.                   |
| Lookup cache           | `cache/resolutions.sqlite` | The results of name lookups, kept for 30 days when a name is found and 1 day when it is not. The app creates it at every start, even in offline mode. |
| Download staging       | `.prefetch/`               | Partial downloads with the suffix `.part`.                                                                                                            |

The macOS voices are not in the data folder, because macOS keeps them.

### Files outside the data folder

The app itself and its preferences live elsewhere.

| Item            | Location                                                                                                    | Content                                                                                                                           |
| --------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| App             | The folder where you moved it, usually `/Applications/Cloudy Reader.app`                                    | The app's code, the name-detection model, and the Java runtime for the OPSIN check.                                               |
| Preferences     | `~/Library/Preferences/com.cloudyreader.Cloudy Reader.plist`                                                | The five saved keys. See [Preferences](#preferences).                                                                             |
| Temporary files | The system temporary folder, in `cloudyreader-opsin-*`, `cloudyreader-selftest-*`, and `cloudyreader-say-*` | A names file for the OPSIN check, the audio of a self-test, and the speech file of a macOS voice. The app removes them after use. |
| Logs            | None                                                                                                        | The app writes no log file.                                                                                                       |

## Preferences

The app has no settings window. It saves five keys in `~/Library/Preferences/com.cloudyreader.Cloudy Reader.plist`, the preference domain `com.cloudyreader.Cloudy Reader`. The domain differs from the bundle identifier, `com.cloudyreader.CloudyReader`. To list the saved values, run this command in Terminal:

```bash
defaults read "com.cloudyreader.Cloudy Reader"
```

The app writes a checkbox, voice, or rotation key when you change it, and `geometry` when the window closes.

| Key              | Type    | Default | What it stores                                                                                                  |
| ---------------- | ------- | ------- | --------------------------------------------------------------------------------------------------------------- |
| `voice`          | Text    | Empty   | The key of the voice you last chose, such as `kokoro:af_heart`, `piper:en_GB-alan-medium`, or `macos:Samantha`. |
| `voice_rotation` | Text    | `none`  | The rotation mode, as an id from the next table. An unknown value reads as `none` and stays in the file.        |
| `read_answer`    | Boolean | `false` | The **Read answer line** checkbox.                                                                              |
| `online_lookups` | Boolean | `true`  | The **Online lookups** checkbox.                                                                                |
| `geometry`       | Binary  | None    | The window size and position.                                                                                   |

The `voice_rotation` key holds one of these ids.

| Id              | Menu label                   |
| --------------- | ---------------------------- |
| `none`          | **No rotation**              |
| `round_robin`   | **Round robin**              |
| `shuffle`       | **Random shuffle**           |
| `us_shuffle`    | **US only (random shuffle)** |
| `men_shuffle`   | **Men only**                 |
| `women_shuffle` | **Women only**               |

The app does not save the speaker number, the rotation deck and last voice, or whether **Spoken script** is open. To clear every saved choice, see [Reset the app](/manual/tasks/voices-and-storage/#reset-the-app).

## Built-in limits

These values are fixed. The app reads none of them from the environment or from a file. A GiB is 1,073,741,824 bytes, about 1.07 GB.

### Name lookups

These limits apply to the name lookups of one reading. For what a lookup sends, see [Privacy](/about/privacy/#what-uses-the-network).

| Limit                                    | Value                                                   |
| ---------------------------------------- | ------------------------------------------------------- |
| Name lookups for one reading, total time | 2.5 seconds, shared with the OPSIN check                |
| One lookup request                       | Up to 4 seconds, within what is left of the 2.5 seconds |
| Lookup request rate                      | 5 requests per second, with no burst                    |
| Retries after HTTP 429 or 503            | 2, after 0.5 and 1 second, if time is left              |
| Lookups at once                          | Up to 16                                                |
| Longest name a lookup sends              | 256 characters                                          |
| Lookup cache life                        | 30 days for a found name, 1 day for a name not found    |

### Downloads

These limits apply to every file of the voice download.

| Limit                                      | Value                                                 |
| ------------------------------------------ | ----------------------------------------------------- |
| Voice download tries for one file          | 3, with waits of 2 and then 4 seconds                 |
| Voice download timeout                     | 10 seconds to connect, 30 seconds of waiting for data |
| Redirects in a voice download              | At most 5, each over HTTPS                            |
| Age at which a partial download is removed | 24 hours                                              |
| File types of a downloaded file            | `.onnx`, `.json`, `.safetensors`, or `.txt`           |

### Chatterbox Turbo and Qwen3-TTS downloads

These limits apply to the downloads of Chatterbox Turbo and Qwen3-TTS. The other downloads run neither the disk check nor the folder check.

| Limit               | Value                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------- |
| File types          | Only `.safetensors`, `.json`, and `.txt`, in the engine's folder or in one sub-folder |
| Free disk space     | 1.1 times the bytes still missing for that engine, plus 1 GiB                         |
| Models folder       | The app must be able to write files to the `models` folder                            |
| When the app checks | When the download starts, and again before it downloads each of the two engines       |

A failed check skips the download of that engine. For the messages, see [Status messages](/manual/reference/status-messages/). For what to do, see [Manage voices and storage](/manual/tasks/voices-and-storage/). For what each engine is, see [Voices and voice engines](/manual/concepts/voice-engines/).

### Reading and audio

These limits apply to a reading and its audio.

| Limit                                          | Value                                                                                                                 |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Speaking speed                                 | 1.0, with no speed control in the window                                                                              |
| Audio cache size                               | No limit                                                                                                              |
| Paste length                                   | No limit; name detection uses pattern matching alone for a text over 1,000,000 characters                             |
| Reading length, Chatterbox Turbo and Qwen3-TTS | At most 8,000 characters of spoken script in one reading. A reading covers every question in the question box.        |
| Reading time, macOS voices                     | 30 seconds plus 0.01 second for each character of the spoken script. A reading that takes longer stops with an error. |
| Spoken script preview                          | Up to 20,000 characters in the question box. A longer text shows the placeholder until you press **Speak**.           |

A reading over the length limit or the time limit shows an error. See [Status messages](/manual/reference/status-messages/).
