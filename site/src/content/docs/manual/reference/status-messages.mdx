This page lists every message in the Cloudy Reader status bar.

## Information messages, warnings, and errors

A message stays until a later one replaces it, unless its row says that it clears. A warning shows a triangle icon, an error a circle icon, and an information message no icon. With rotation, the messages read "Preparing with _name_…" and "Playing _n_ s with _name_."; a _name_ reads like Heart (female, Kokoro).

| Message                                                                                                                                      | What it means and what to do                                                                                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Loading voices…                                                                                                                              | The app lists the voices, then it clears.                                                                                                                                     |
| [Downloading _engine_… _N_% (_x_ of _y_ MB)](/manual/troubleshooting/#the-voice-download-does-not-progress)                                  | A narrow window drops the sizes. Failed files count: check the **Voice** menu.                                                                                                |
| Voices downloaded.                                                                                                                           | All downloads finished. Nothing to do.                                                                                                                                        |
| [Paste a question first.](/manual/troubleshooting/#the-app-finds-nothing-to-read)                                                            | The question box has no text. Paste or type one.                                                                                                                              |
| Preparing…                                                                                                                                   | The app prepares the reading. Wait.                                                                                                                                           |
| [Preparing… loading _engine_ (first use only)](/manual/troubleshooting/#the-first-use-of-an-engine-is-slow)                                  | The voice engine loads its model, so the reading takes longer. Wait.                                                                                                          |
| Playing _n_ s.                                                                                                                               | The sound plays. It clears at the end.                                                                                                                                        |
| Repeating.                                                                                                                                   | Repeat plays it again. It clears at the end.                                                                                                                                  |
| Stopped.                                                                                                                                     | Stop ended the sound. Repeat plays it again.                                                                                                                                  |
| [_name_ is not ready: _reason_. Using _name_.](/manual/troubleshooting/#the-voice-changes-by-itself)                                         | The saved voice is not ready. It clears when that voice is ready or you choose one.                                                                                           |
| [No voice is installed.](/manual/troubleshooting/#no-voice-is-installed)                                                                     | Information during a download, a **warning** if no voice arrives. It clears when a voice appears.                                                                             |
| [Some voices could not be downloaded. They are tried again at the next start.](/manual/troubleshooting/#some-voices-could-not-be-downloaded) | **Warning.** The tooltip lists the failed files. Quit and reopen the app to retry.                                                                                            |
| [_engine_ not downloaded: _reason_](/manual/troubleshooting/#voices-from-one-engine-are-missing)                                             | **Warning.** Fix the reason, then quit and reopen the app. The tooltip lists every skip.                                                                                      |
| No installed voice matches “_mode_”; using the selected voice.                                                                               | **Warning.** No voice fits the mode, so the selected voice plays. See [When no voice fits](/manual/reference/voices/#when-no-voice-fits).                                     |
| [Warning: _text_](/manual/troubleshooting/#a-word-sounds-wrong)                                                                              | The reading plays. "_engine_ cannot take IPA: …" means the voice engine says the named words as printed. See [Pronunciation guides](/manual/reference/pronunciation-guides/). |
| _n_ warnings: _text_; _text_                                                                                                                 | Several warnings. Read each one.                                                                                                                                              |
| [Error: nothing to read](/manual/troubleshooting/#the-app-finds-nothing-to-read)                                                             | The app found no question. Paste it again.                                                                                                                                    |
| [Error: cannot run /usr/bin/afplay: _error_ or Error: WAV not found: _path_](/manual/troubleshooting/#the-player-cannot-start)               | macOS cannot start the player, or the audio file is gone.                                                                                                                     |
| [Error: _engine_ reads at most 8,000 characters at once; this has _N_](/manual/troubleshooting/#a-voice-error-appears)                       | The spoken script is longer than the voice engine reads at once. Read fewer questions.                                                                                        |
| [Error: _engine_ could not say '_part_'; try another voice](/manual/troubleshooting/#a-voice-cannot-say-a-short-part)                        | The voice engine made no usable sound for a part, such as a single hard word. Choose another voice.                                                                           |
| [Error: damaged: SHA-256 mismatch for _file_](/manual/tasks/voices-and-storage/#check-which-voices-are-installed)                            | A model file is damaged. Later readings fail at once with the same reason until you quit the app.                                                                             |
| Error: _first line_                                                                                                                          | A step failed. Point to the message to read it all. See [A voice error appears](/manual/troubleshooting/#a-voice-error-appears) or [Get help](/manual/get-help/).             |
