This page lists every voice, how a voice label reads, the menu order, why a voice is dimmed, and the six rotation modes.

## Voice engines

A [voice engine](/manual/reference/glossary/#voice-engine) makes a set of voices on your Mac. This table compares the engines in menu order. For what the engines are and how to choose a voice, see [Voices and voice engines](/manual/concepts/voice-engines/).

| Engine           | Voices        | Key prefix         | Name in the label                                             | Precision in the label                                                                        |
| ---------------- | ------------- | ------------------ | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Kokoro           | 28            | `kokoro`           | The part of the id after the underscore, such as Heart        | `bf16`. A letter grade from the model's `VOICES.md` file ranks the voices, from A down to F+. |
| Chatterbox Turbo | 1             | `chatterbox_turbo` | Built-in                                                      | `4-bit`. The voice has no grade.                                                              |
| Qwen3-TTS        | 2             | `qwen3_tts`        | The preset name, such as Aiden                                | `8-bit`. The voices have no grade.                                                            |
| Piper            | 5             | `piper`            | The name part of the file name, with capitals, such as Lessac | The quality in the voice's config file: `medium` for every voice                              |
| macOS            | Varies by Mac | `macos`            | The name that macOS gives the voice, such as Samantha         | The tier of the voice: `Standard`, `Enhanced`, or `Premium`                                   |

The key of a voice is the key prefix of its engine, a colon, and the id of the voice, as in `kokoro:af_heart`. The id of a macOS voice is its name in macOS, with its tier when it has one, as in `macos:Ava (Premium)`. Error messages and the saved voice setting use the key.

## Voice labels

A voice label is the text of one row in the **Voice** menu. The closed menu shows the same label for the voice that you chose. A label reads _name_ (_accent_, _gender_) · _engine_ · _precision_, with a middle dot between the parts.

This table explains each part.

| Part      | What it shows                                               | Where it comes from                                                                                                                                               |
| --------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Name      | The name of the voice, such as Heart or Lessac.             | The engine's name for the voice, without a gender suffix. A Piper name gets capital letters, and the one voice of Chatterbox Turbo shows Built-in.                |
| Accent    | US, UK, AU, CA, IE, IN, NZ, ZA, or Scotland.                | The region of the language code: `en-US` shows US, and `en-GB` shows UK. Another region shows its own code. A code with no region, such as `en`, shows no accent. |
| Gender    | female or male                                              | The gender label of the voice. A voice with no known gender shows none.                                                                                           |
| Engine    | Kokoro, Chatterbox Turbo, Qwen3-TTS, Piper, or macOS.       | The voice engine that makes the voice.                                                                                                                            |
| Precision | `bf16`, `4-bit`, `8-bit`, a Piper quality, or a macOS tier. | The format of the model for Kokoro, Chatterbox Turbo, and Qwen3-TTS. The quality in the config file for Piper. The tier that macOS names for a macOS voice.       |

The brackets after the name hold only what the app knows: (US, female), (male), or (US). A voice with neither fact shows no brackets. A Kokoro grade never appears in a label. A voice that is not ready adds a dash and its reason after the precision: see [Dimmed voices and their reasons](#dimmed-voices-and-their-reasons).

These rows are examples of each case.

| Row                                             | Example                                                  |
| ----------------------------------------------- | -------------------------------------------------------- |
| An installed Kokoro voice                       | Heart (US, female) · Kokoro · bf16                       |
| A Kokoro voice with a British accent            | Emma (UK, female) · Kokoro · bf16                        |
| An installed Piper voice                        | Lessac (US, female) · Piper · medium                     |
| An installed Qwen3-TTS voice                    | Aiden (US, male) · Qwen3-TTS · 8-bit                     |
| A Qwen3-TTS voice with no region                | Ryan (male) · Qwen3-TTS · 8-bit                          |
| An installed Chatterbox Turbo voice             | Built-in · Chatterbox Turbo · 4-bit                      |
| A macOS voice with a known gender               | Daniel (UK, male) · macOS · Standard                     |
| A macOS voice with no known gender              | Fred (US) · macOS · Standard                             |
| A Kokoro voice that is not downloaded           | Adam (US, male) · Kokoro · bf16 — not downloaded yet     |
| A Chatterbox Turbo voice that is not downloaded | Built-in · Chatterbox Turbo · 4-bit — not downloaded yet |

Point to a row to read more. The tooltip of a dimmed Chatterbox Turbo or Qwen3-TTS row holds its whole reason. The tooltip of an installed Kokoro row gives the grade, as in "Published grade A". The tooltip of the closed menu says the label in words, as in "Heart, American English, female. Kokoro, bf16."

## macOS voices

The macOS voices come from your Mac and not from the app, so their number, names, and tiers depend on the Mac. The figure shows the end of the **Voice** menu on a Mac with three macOS voices.

This table gives the rules that the app follows.

| Item           | Rule                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Which voices   | The English voices that macOS lists, without the novelty voices such as Albert, Bubbles, Cellos, and Whisper. A voice in another language never appears. |
| Name           | The name that macOS gives the voice, without its tier.                                                                                                   |
| Precision      | The tier in the macOS name: Premium or Enhanced. A voice with no tier in its name is Standard.                                                           |
| Order          | Premium voices first, then Enhanced, then Standard. Voices of one tier sort by name.                                                                     |
| Gender         | Known only for the voices on a list of names inside the app, such as Samantha and Daniel. Any other macOS voice shows no gender and never rotates.       |
| Voices you add | The app reads the list once, at launch. A voice that you add in **System Settings** appears after you quit the app and open it again.                    |
| Download       | None. The app downloads nothing for a macOS voice, and the data folder holds none of its files.                                                          |
| No heading     | The menu shows no macOS heading when macOS lists no English voice, or when the `say` command of macOS is missing.                                        |

## Menu order and the default voice

Each voice engine has a heading in the **Voice** menu. The headings are labels, not choices. The menu sorts the voices by these keys, in this order.

| Sort key      | Rule                                                                                                                                                                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Engine        | Kokoro, then Chatterbox Turbo, then Qwen3-TTS, then Piper, then macOS.                                                                                                                                                                                           |
| Grade or tier | The best first. Kokoro grades run from A down to F+. Piper qualities run from high to medium, low, and `x_low`. macOS tiers run from Premium to Enhanced and Standard. A voice with no grade comes last, and no Chatterbox Turbo or Qwen3-TTS voice has a grade. |
| Name          | Voices with the same grade or tier sort by name, ignoring case.                                                                                                                                                                                                  |

Kokoro lists every voice once its model files are installed and pass the SHA-256 check. Piper lists a voice only when both of its files exist. Chatterbox Turbo and Qwen3-TTS list their voices as ready once all of their files are installed and valid. Until then, they list dimmed rows with a reason. The macOS engine lists the voices that macOS reports and never dims a row. An engine that the app does not include, has no files for, or cannot run on this Mac shows no heading and no rows.

At each start, the app selects the voice that you chose last, if it is installed. Otherwise it selects the first installed voice in the menu. If the voice that you chose last is dimmed with a reason, the status bar says why: see [Status messages](/manual/reference/status-messages/). The app saves a voice only when you choose it, so a finished voice download can move an automatic selection to a better voice.

| Situation at the start                                         | Selected voice                                         |
| -------------------------------------------------------------- | ------------------------------------------------------ |
| You chose a voice before, and it is installed                  | That voice                                             |
| You chose a voice before, and it is not installed              | The first installed voice in the menu                  |
| No saved choice, and every voice is installed                  | Heart (US, female) · Kokoro · bf16                     |
| No saved choice, and only Piper and macOS voices are installed | Alan (UK, male) · Piper · medium                       |
| No saved choice, and only macOS voices are installed           | The first macOS voice in the menu: the best tier first |

To download missing voices or add a Piper voice, see [Manage voices and storage](/manual/tasks/voices-and-storage/).

## Dimmed voices and their reasons

A voice that cannot run is dimmed and cannot be chosen. Its row ends with a dash and the reason. The row keeps a short reason whole. For a long reason it keeps the text before the first colon, or its first characters followed by an ellipsis. A dimmed Chatterbox Turbo or Qwen3-TTS row has a tooltip that shows the whole reason. For the fix for each reason, see [Voices from one engine are missing](/manual/troubleshooting/#voices-from-one-engine-are-missing). The first part of the figure shows dimmed rows while their engine downloads. The second part shows the status bar at the first reading with an engine.

  alt="The Voice menu open while Qwen3-TTS downloads, with its rows Aiden and Ryan dimmed and ending in not downloaded yet. A second strip shows the status bar text Preparing… loading Chatterbox Turbo (first use only)."
  caption="While an engine downloads, its voices stay dimmed and say why, and the first reading with an engine loads its model first."

This table lists every reason that a row can show.

| Reason                                           | What it means                                                                                                                                                                              |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| not downloaded yet                               | The files of the engine are not on the Mac yet, or the file of a Kokoro voice is missing.                                                                                                  |
| offline: not downloaded                          | Offline mode is on, so the app downloads nothing.                                                                                                                                          |
| not enough disk space: needs _X_ GB, _Y_ GB free | The Mac has less free space than the download needs. The amount needed is the size of the missing files plus a margin.                                                                     |
| the models folder is not writable                | The app cannot add files to the `models` folder.                                                                                                                                           |
| damaged: _detail_                                | A file in the engine's folder fails a check. The detail names a wrong size, a link in place of a file, a pickle-capable file, weights that the app does not expect, or a SHA-256 mismatch. |
| waiting for a Qwen3 decoder fix (_detail_)       | The app cannot use the Qwen3-TTS decoder, so it does not run or download Qwen3-TTS.                                                                                                        |

## Rotation modes

**Rotation** chooses how **Speak** picks the voice for each reading. The app saves the mode between launches. A mode picks from its pool, the installed voices that qualify. For a guided lesson, see [Practice with voice rotation](/manual/tutorials/voice-rotation/).

<Figure
  src="rotation-light.svg"
  dark="rotation-dark.svg"
  alt="The Rotation menu open with six modes: No rotation, Round robin, Random shuffle, US only (random shuffle), Men only, and Women only."
  caption="The six rotation modes, in menu order."
  frame="window"
/>

The last column counts the Kokoro, Qwen3-TTS, and Piper voices in the pool when every voice is installed. The macOS voices that qualify come on top.

| Mode                         | The next voice is                                                                       | Voices in the pool |
| ---------------------------- | --------------------------------------------------------------------------------------- | ------------------ |
| **No rotation**              | The voice in the **Voice** menu, with the number in the **Speaker** box.                | Not used           |
| **Round robin**              | The voice after the last one used, in menu order. After the last voice comes the first. | 35                 |
| **Random shuffle**           | The next voice from a shuffled deck of the pool.                                        | 35                 |
| **US only (random shuffle)** | The next voice from a shuffled deck of the en-US voices in the pool.                    | 24                 |
| **Men only**                 | The next voice from a shuffled deck of the voices labeled male.                         | 17                 |
| **Women only**               | The next voice from a shuffled deck of the voices labeled female.                       | 18                 |

**Round robin** takes the first voice of the pool when no voice was used yet, or when the last voice left the pool. With every voice installed, that voice is the first voice in the menu, Heart (US, female) · Kokoro · bf16.

The four shuffle modes deal a deck, which is the pool voices in random order. No voice repeats until the deck is empty. Each deck opens with a voice other than the one used last, when the pool has two or more voices.

## Which voices rotate

A voice joins the pool when it meets all four conditions:

- It is installed.
- It has exactly one speaker.
- It is an English voice with a known gender. Every Kokoro voice qualifies, because its id gives the gender. Both Qwen3-TTS voices qualify. The Chatterbox Turbo voice has no gender label, so it never qualifies. Of the Piper voices, only the voices in the Piper table above qualify. Of the macOS voices, only a voice with a known gender qualifies, as the [macOS voices](#macos-voices) section says.
- It fits the mode. **US only (random shuffle)** needs the language en-US, **Men only** needs male, and **Women only** needs female.

The Qwen3-TTS voice Ryan has the language en, with no region, so **US only (random shuffle)** takes Aiden and skips Ryan. **Men only** takes both. A macOS voice joins **US only (random shuffle)** only when macOS gives it the language en-US.

The pool keeps the menu order and counts each voice once. The app rebuilds the pool from the voice list at the start of every reading.

A Piper voice that you add by hand never rotates, because the app knows no gender for it. A macOS voice with no known gender never rotates either, and neither does a voice with several speakers or in a language other than English.

## When rotation moves on

This table lists what moves rotation and what leaves it alone.

| Event                                                      | What happens                                                                                                                                                                                                                                                         |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A reading starts                                           | Rotation picks the next voice, after three checks pass. A voice is selected, no reading is in preparation, and the question box has text.                                                                                                                            |
| Rotation picks a voice                                     | The **Voice** menu and the **Speaker** box stay as you set them. Rotation uses only single-speaker voices, so it sends no speaker number. The status bar names the voice: "Preparing with Daniel (male, Kokoro)…", then "Playing 32.7 s with Daniel (male, Kokoro)." |
| A reading fails after the pick                             | The voice still counts as used.                                                                                                                                                                                                                                      |
| You press **Repeat**                                       | Rotation does not move. The stored audio plays again, so it keeps the voice of the last reading.                                                                                                                                                                     |
| You change the mode                                        | The app drops the current deck and keeps the last voice used. **Round robin** continues after that voice, and the next deck opens with a different voice.                                                                                                            |
| The voice list changes, for example after a voice download | A voice that left the pool drops out of the current deck. A voice that joined the pool waits for the next deck.                                                                                                                                                      |
| You quit the app                                           | The deck and the last voice are lost. The mode is saved.                                                                                                                                                                                                             |

## When no voice fits

When no installed voice fits the mode, the pool is empty. The reading then uses the voice and the speaker that you chose in the **Voice** menu. The status bar shows this warning while the reading prepares, and it stays after the sound ends:

```text
No installed voice matches “Men only”; using the selected voice.
```

The text names the mode that found no voice. For example, **Men only** finds no voice when no installed voice is labeled male. This can happen during the first voice download, when only a few voices are installed. A warning about the reading itself replaces this message.
