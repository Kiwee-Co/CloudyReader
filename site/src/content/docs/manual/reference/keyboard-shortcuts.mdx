This page lists every keyboard shortcut in Cloudy Reader and the tab order of the window. The shortcuts belong to menu commands, so Cloudy Reader must be the active app.

<div class="cr-cheatsheet cr-cheatsheet--2col">

<div>

## Reading

The Reading menu holds these commands. Each is available under the same conditions as its button, listed in [Main window](/manual/reference/window/#buttons-and-when-they-are-available). The Tooltip shows column gives the glyphs in the button tooltips.

| Action              | Keys                            | Tooltip shows  |
| ------------------- | ------------------------------- | -------------- |
| **Speak**           | Command-Return or Command-Enter | <kbd>⌘↵</kbd>  |
| **Speak Clipboard** | Command-Shift-V                 | <kbd>⇧⌘V</kbd> |
| **Repeat**          | Command-R                       | <kbd>⌘R</kbd>  |
| **Stop**            | Command-Period (.)              | <kbd>⌘.</kbd>  |

## Editing

The Edit menu holds these commands. They act on the question box or the **Spoken script** view, whichever has focus.

## Window and app

**Close Window** and **Quit Cloudy Reader** both end the app, because it has one window.

| Action                  | Keys      |
| ----------------------- | --------- |
| **Close Window**        | Command-W |
| **Quit Cloudy Reader**  | Command-Q |
| **Minimize**            | Command-M |
| **Zoom**                | None      |
| **About Cloudy Reader** | None      |

## Moving between controls

Tab in the question box moves focus out of the box. The tab order follows the rows of this table, and the controls inside each row. Shift-Tab walks the same order backward. Tab skips disabled buttons and the hidden **Speaker** box. After the **Spoken script** view, Tab returns to the question box. For a full walk-through, see [Use VoiceOver and the keyboard](/manual/tasks/voiceover-and-keyboard/).

| Window part        | Controls, in tab order                                                        |
| ------------------ | ----------------------------------------------------------------------------- |
| Question           | Question box                                                                  |
| Voice and rotation | **Voice**, **Speaker** (only for a voice with several speakers), **Rotation** |
| Options            | **Read answer line**, **Online lookups**                                      |
| Buttons            | **Paste**, **Speak Clipboard**, **Repeat**, **Stop**, **Speak**               |
| Spoken script      | **Spoken script** button, then the **Spoken script** view                     |
