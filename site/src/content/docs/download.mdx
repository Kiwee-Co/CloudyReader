## Check your Mac

Cloudy Reader needs a Mac with Apple silicon and macOS 26.2 or later. [Check your Mac](/manual/getting-started/#check-your-mac) shows how to read your chip and macOS version, and lists the disk space and network needs. If a requirement fails, see [Your Mac is not supported](/manual/troubleshooting/#your-mac-is-not-supported).

## Check the download

The SHA-256 is a fingerprint of the file. If your copy has the same SHA-256, it is the same file as the published one. Each line gives a SHA-256 and the file name:

```text
f30f0854f723ff8a6699c2492754d7d61841d06da62c2167558e5850c2a7f8a6  Cloudy-Reader-0.0.3-macos-arm64.dmg
3a008a335f240ecb2f8302f60ce7f8b9647f74dad7c12f98e0d4ba8ee33f7ec1  Cloudy-Reader-0.0.3-macos-arm64.zip
```

To check your copy:

<Steps>

1. Open Terminal. It is in **Applications > Utilities**.
2. Go to the folder that holds the file. If your browser saves files in Downloads, run this command:

   ```bash
   cd ~/Downloads
   ```

3. Run the check for the file you downloaded. For the disk image:

   ```bash
   echo "f30f0854f723ff8a6699c2492754d7d61841d06da62c2167558e5850c2a7f8a6  Cloudy-Reader-0.0.3-macos-arm64.dmg" | shasum -a 256 -c
   ```

   For the zip:

   ```bash
   echo "3a008a335f240ecb2f8302f60ce7f8b9647f74dad7c12f98e0d4ba8ee33f7ec1  Cloudy-Reader-0.0.3-macos-arm64.zip" | shasum -a 256 -c
   ```

</Steps>

The output must read `Cloudy-Reader-0.0.3-macos-arm64.dmg: OK` for the disk image, or `Cloudy-Reader-0.0.3-macos-arm64.zip: OK` for the zip.

Any other output means the download is damaged or is not this release. Delete the file and download it again. See [The checksum does not match](/manual/troubleshooting/#the-checksum-does-not-match). If the mismatch repeats, follow [Report a security issue](/manual/get-help/#report-a-security-issue).

For a school or work review, [Security and code signing](/about/security/) explains the signature, and [Privacy](/about/privacy/) lists every network use.

## Install the app

### Install from the disk image

<Steps>

1. Double-click the disk image to open it.
2. Drag **Cloudy Reader** onto the **Applications** link beside it. Do this before you open the app.
3. Eject the disk image: click the eject button next to the **Cloudy Reader** volume in the Finder sidebar.
4. Open Cloudy Reader from the **Applications** folder. macOS blocks the first launch until you approve it once. Follow [Approve the app](/manual/tasks/first-open/#approve-the-app).

</Steps>

### Install from the zip

<Steps>

1. Double-click the zip in Finder to unzip it.
2. Drag **Cloudy Reader** to the **Applications** folder. Do this before you open the app.
3. Open Cloudy Reader. macOS blocks the first launch until you approve it once. Follow [Approve the app](/manual/tasks/first-open/#approve-the-app).

</Steps>

Cloudy Reader is in the **Applications** folder. The app is signed ad hoc and is not notarized, which is why macOS asks for the approval.

Next, [open the app](/manual/getting-started/#open-the-app), let the voices download, and hear a sample question. To update or remove the app later, see [Install, update, and uninstall](/manual/tasks/install/).
