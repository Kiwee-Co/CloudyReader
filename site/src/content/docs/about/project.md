## What Cloudy Reader is

Paste a National Science Bowl question, and Cloudy Reader reads it aloud on your Mac. It says formulas, units, and fractions in words, and it works without a network after the first launch.

It is made for students who practice alone, coaches who run practice rounds, and moderators who rehearse hard terms. See [Get started](/manual/getting-started/) to install it.

## Independence

Cloudy Reader is an independent project. It is not affiliated with, endorsed by, or sponsored by the U.S. Department of Energy or the National Science Bowl.

The app's reading is not official, and it does not set how a moderator must read a question.

## Who makes it

Cloudy Reader is an open-source project. Its source code is in the [Kiwee-Co/CloudyReader](https://github.com/Kiwee-Co/CloudyReader) repository on GitHub, under the Apache License 2.0, and the app's copyright line names the Cloudy Reader authors.

See [Licenses and credits](/about/licenses/) for the licenses of the components that the app bundles.

## Project status

The current version is REL-VERSION, and the first public release was 0.0.1. Cloudy Reader needs a Mac with Apple silicon and macOS REL-MACOS-FLOOR or later. See [Check your Mac](/manual/getting-started/#check-your-mac) for the full requirements and [Release notes](/about/release-notes/) for the known limits.

## Contribute

Changes to the app and to this manual land as pull requests on GitHub. Read [Contribute](/developer/contributing/) for the branch flow, the commit style, and the required checks. Read [Build from source](/developer/building/) to run the app from a checkout.

## Contact

Report a problem or ask a question in [GitHub Issues](https://github.com/Kiwee-Co/CloudyReader/issues). [Get help](/manual/get-help/) lists what to include. To report a security issue privately, see [Report a security issue](/manual/get-help/#report-a-security-issue).
